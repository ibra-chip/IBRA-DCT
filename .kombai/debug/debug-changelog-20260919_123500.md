- **File:** `script.js`
- **Change:** The `.remove-user` click handler now sends `DELETE /api/users/:id` immediately and refreshes the user view after success.
- **Reason:** The requested UX is immediate deletion when the secondary removal button is clicked.
- **Safety:** The button is still rendered only for other users when the current session is an owner/gerant. Backend authentication, owner authorization, self-delete protection, and the API route were not changed.
- **Validation rule:** No real user was clicked or deleted during debugging; only nonexistent IDs may be used for safe API checks.
